# TipKit

A small multilingual restaurant tipping practice calculator for international students in the United States.

## Run locally

Open `outputs/index.html` in a web browser.

## Deploy with GitHub Pages

The included GitHub Actions workflow publishes the static site from `outputs/` whenever changes are pushed to the `main` branch. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

The calculator supports Traditional Chinese, English, and Spanish; dine-in, takeout, and bar scenarios; editable subtotal, tax, and tip; and a credit-card receipt preview.
